# Reference gallery: the quality bar

Approved diagrams (all made with Higgsfield, dark theme). They show the **craft** to match: rhythm,
density, line quality, balance, hierarchy. Learn the form from them, never copy their pixels, and keep
the html engine's own rules (real Poppins, tokens, text sizes).

| File | Look at |
|---|---|
| `two-outputs.png` | Dense, evenly spaced identical bars as "a document"; accent-outlined numbered rows whose bars line up with the column labels; the quieter rest; one short accent arrow. Rebuilt in `examples/comparison.html`. |
| `six-steps.png` | Numbered accent circles on one thin line; a branch dropping into quiet pills with clean right-angled connectors. |
| `two-views-venn.png` | Big calm circles, the overlap as the only fill, short notes placed in each region. |
| `impact-effort-matrix.png` | Axes with low/high ends, generous quadrants, one filled quadrant, title + example per quadrant. |
| `when-to-add-more.png` | A central rotated accent bar, lanes with short connectors, one pill spanning the bar where before = after. |
